📧 Email via EmailJS Get free account →

EmailJS lets you send emails directly from the browser with no backend. Free tier: 200 emails/month.

Setup (5 minutes):

  1. Sign up at emailjs.com → free account
  2. Add an email service (Gmail, Outlook, etc.) → copy the Service ID
  3. Create an email template. Use these variables in your template:
    {{to_name}} · {{tracking_number}} · {{commodity}} · {{eta}} · {{origin}} · {{destination}} · {{message}}
  4. Copy the Template ID and your account's Public Key
  5. Paste all three above and click Save
📱 SMS via ClickSend Create free account →

ClickSend sends SMS to any phone number worldwide including Iraq, USA and Europe. You get $2 AUD free credit on signup (≈10–15 messages to test). Accepts Bitcoin and credit card for top-ups. No proxy or server needed — connects directly.

Setup (3 minutes):

  1. Go to dashboard.clicksend.com/signup and create a free account
  2. Log in → click your name top-right → Account Settings → API Credentials
  3. Copy your Username and API Key and paste them above
  4. Optionally set a Sender name (up to 11 characters, shown instead of a number) — leave blank to use ClickSend default
  5. Click Save settings then Test SMS to verify it works
  6. To top up with Bitcoin: Dashboard → Billing → Top Up → choose BTC
